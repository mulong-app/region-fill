Region Fill

一筆書きの曲線で区切り、隣り合う区画を別の色で塗り分けます
設定の保存
最後に使った設定は自動で保存され、次回起動時に復元されます。「書き出す」「読み込む」はJSONファイルでのやりとりです。書き出したファイルは region_fill.py --config ファイル名 でも使えます
線の形
長いほど交差と区画が増えます（画面の短辺の何倍か）
これより急なカーブ・小さなループを作りません
曲がりの入り・抜けの長さ
曲がりの回数を制限すると線が絡み合います（2回はばらつきが大きく、まれに数十秒かかります。30秒で打ち切り）
重心と重なり回避
同じ場所を線が何度も並んで通らないようにします
線の見た目
0 で線なし（塗りだけ）
塗りの色
4色以上。クリックで色を変更、×で削除
プリセットを選ぶと、線の形はそのままで色だけ変わります
0 = 各色を均等に使う / 1 = 完全にランダム
サイズ
線の太さ・最小半径は画面の短い辺に対する比率なので、サイズを変えても見た目の印象は同じです。生成時間も変わりません
